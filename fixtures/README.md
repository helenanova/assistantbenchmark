# Fixtures

Synthetic stand-ins for data that would otherwise need a user's real accounts.
Nothing here is real: companies, people, confirmation numbers, and prices are invented.

- calendar/week.ics - one synthetic week (Mon 2026-09-14 to Sun 2026-09-20, America/Los_Angeles) with recurring events, mixed RSVPs, and a weekend event.
- calendar/appointment.eml, flight.eml, hotel.eml, interview.eml - synthetic confirmation emails.
- data/*.csv, *.json - small datasets with planted errors (invalid values, duplicates, mixed formats, anomalies, wrong totals) for the data-qa and docs-sheets cases.
- text/*.txt - short texts with planted typos (proofreading) or messy structure (outlining, extraction).
